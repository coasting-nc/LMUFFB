## 2024-05-15 - Documentation as Micro-UX

**Learning:** In a closed-source project where documentation is the primary interface, technical inaccuracies (like outdated config file extensions or incorrect step ordering) are significant UX friction points. Using GitHub-style `[!WARNING]` alerts significantly improves the scannability of "out of date" notices compared to plain text blockquotes.

**Action:** Prioritize accuracy of file extensions and setup sequences in documentation to ensure the "first run" experience is frictionless. Use structured alerts for visibility.
