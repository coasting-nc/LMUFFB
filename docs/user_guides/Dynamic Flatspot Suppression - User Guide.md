# Dynamic Flatspot Suppression - User Guide

> Updated November 2026 (app 0.8.007).

**Dynamic Flatspot Suppression and the fixed-buzz option that came with it are no longer part of LMUFFB.** They were removed in 2026, and the app no longer shows these controls. Older profiles that contain these settings still load; the settings are simply ignored.

If your wheel shakes with a rhythm that speeds up with the car (for example after flat-spotting a tyre), or buzzes all the time:

* Lower **Road Texture** and the other vibration strengths.
* Raise **Steering Smoothing** a little if the steering itself feels grainy.
* Check your wheel driver's own damping and smoothing settings.
* If the problem stays, open an issue on GitHub and attach a log.
